Automatic Client Bootstrap

These scripts install this instance's client mod pack{% if fika_installed %}, including its matching Fika client{% endif %}, and add the server to your current SPT launcher. No separate Fika Installer is needed.

Linux requires Bash and Python 3; Windows requires Windows PowerShell 5.1 or PowerShell 7. Your SPT/game installation and Linux Wine/Proton setup must already exist and match this server.

{% call icons::download() %}{% endcall %} PowerShell Script (Windows) {% call icons::download() %}{% endcall %} Bash Script (Linux)

Review the downloaded script, then preview without changing your client. On Windows, the command below sets execution policy only for that PowerShell process; it does not change system policy or override organization policy:

bash quma-bootstrap.sh --spt-dir "/path/to/SPT" --dry-run
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\quma-bootstrap.ps1 -SptDir 'C:\Games\SPT' -DryRun

Remove --dry-run / -DryRun and confirm to apply. Run from the SPT directory to omit the target argument. Existing editable mod configs and other launcher servers/profiles are preserved; replaced files are backed up under .quma-bootstrap-backups/. The pack can be large, so allow room for downloading, staging and backups.
